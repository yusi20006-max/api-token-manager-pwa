# مدیر توکن‌های API (PWA)

یک Progressive Web App تمیز و خودگردان برای مدیریت توکن‌های API از سایت‌های مختلف.

## قابلیت‌ها

- اضافه / ویرایش / حذف API (نام، Base URL، Token، نوت، آدرس تست اختیاری)
- کپی کردن Token و Base URL
- نمایش / مخفی کردن Token
- چک وضعیت تکی و چک همه
- نمایش وضعیت رنگی + زمان آخرین چک + پیام آخرین پاسخ
- ساعت زنده
- جستجو
- Dark / Light Mode
- Export / Import به صورت JSON
- نصب به عنوان PWA (افلاین)
- ذخیره‌سازی کاملاً محلی (LocalStorage)

## نحوه استفاده

1. فایل `index.html` را باز کنید (یا از GitHub Pages استفاده کنید).
2. برای نصب به عنوان اپ، از منوی مرورگر «Add to Home Screen» را انتخاب کنید.

## توضیح مهم

به دلیل محدودیت CORS، برخی APIها از داخل مرورگر قابل چک نیستند حتی اگر کلید معتبر باشد. در این حالت پیام مناسب نمایش داده می‌شود.
